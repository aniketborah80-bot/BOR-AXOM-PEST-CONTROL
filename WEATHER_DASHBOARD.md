# Weather Dashboard

A beautiful, responsive real-time weather dashboard that fetches data from OpenWeatherMap API.

## 🌟 Features

- **Real-time Weather Data** - Current weather conditions for any city
- **5-Day Forecast** - Extended weather forecast with daily predictions
- **Geolocation Support** - Get weather for your current location
- **Search Functionality** - Search weather by city name
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Weather Details** - Temperature, humidity, wind speed, pressure, and more
- **Beautiful UI** - Modern gradient design with smooth animations

## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling and animations
- **JavaScript (Vanilla)** - Functionality
- **OpenWeatherMap API** - Weather data
- **Font Awesome** - Icons

## 📋 API Details

This project uses the **OpenWeatherMap API** (Free Tier):
- Current weather endpoint: `/weather`
- Forecast endpoint: `/forecast`
- Free API key included for testing

## 🚀 How to Use

1. **Search by City**: Enter any city name and click "Search"
2. **Get Your Location**: Click "My Location" button to get weather for your current location
3. **View Details**: See current temperature, humidity, wind speed, and pressure
4. **Check Forecast**: View 5-day weather forecast below

## 🔧 Customization

To use your own API key:
1. Sign up at [OpenWeatherMap](https://openweathermap.org/api)
2. Get your free API key
3. Replace `API_KEY` value in the JavaScript section

```javascript
const API_KEY = 'YOUR_API_KEY_HERE';
```

## 📄 Installation
